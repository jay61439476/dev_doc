# ADR-NNN：决策标题

- 状态：提议 / 已接受 / 已拒绝 / 已废弃 / 被替代
- 日期：YYYY-MM-DD
- 决策人：
- 相关 Issue / PR：

## 1. 背景与问题
描述业务背景、技术现状和需要解决的问题。

## 2. 决策目标与约束
列出目标、不可违反的约束、兼容性要求和安全要求。

## 3. 假设与未知条件
区分已经验证的事实、待验证假设和待确认事项。

## 4. 候选方案
描述当前方案及备选方案。

## 5. 评估与论证
比较正确性、复杂度、性能、安全、成本、兼容性、可测试性和维护性；记录反对意见及反例。

## 6. 最终决策
说明采用什么方案、理由，以及不选择其他方案的原因。

## 7. 风险与影响
列出剩余风险、影响范围、依赖及缓解措施。

## 8. 验证与回滚
说明验证步骤、验收标准、回滚条件和回滚方式。

## 9. 后续行动
列出需要创建或更新的 Issue、PR、文档和负责人。
